
```mermaid root((血液生理终章<br>凝血·抗凝·血型))
    凝血核心三步
      激活因子Ⅹ
        外源性启动（Ⅲ-Ⅶ）
        内源性完成（Ⅸ→Ⅷ加速）
        生理实质路径：Ⅲ-Ⅶ→Ⅸ→Ⅹ
      凝血酶原→凝血酶
      纤维蛋白原→纤维蛋白
    关键因子与辅因子
      三大辅因子（非酶，放大作用）
        Ⅲ因子（组织因子）：提升Ⅶ活性1000倍
        Ⅴ因子：提升凝血酶原激活1万倍
        Ⅷ因子：提升Ⅸa激活Ⅹ速度20万倍（缺乏→血友病甲）
      维生素K依赖因子（Ⅱ,Ⅶ,Ⅸ,Ⅹ）
        肝脏合成，需VK
        临床：慢性胰腺炎（缺原料）→注射VK有效；肝硬化（缺合成）→无效
    凝血调控与抗凝
      凝血途径
        外源性：Ⅲ-Ⅶ，被TFPI抑制
        内源性：Ⅻ启动
        生理捷径：Ⅲ-Ⅶ直接激活Ⅸ，绕过TFPI
      抗凝系统
        抗凝血酶（AT）：直接灭活凝血酶（60-70%）
        肝素：增强AT活性（体内外均效，间接抗凝）
        华法林：抑制VK依赖因子合成（仅体内，起效慢，需肝素搭桥）
        蛋白C系统：灭活Ⅴa/Ⅷa，限制凝血局部化
        TFPI：负反馈抑制外源性
      纤溶系统
        tPA/uPA激活纤溶酶原→纤溶酶→降解纤维蛋白
        D-二聚体：排除血栓（阴性可排除），确诊需CTPA
    临床检验与用药
      APTT→内源性（Ⅷ因子），监测肝素
      PT→外源性（Ⅶ因子），监测华法林（INR目标2.0-3.0）
    血型与输血
      ABO系统
        按红细胞抗原分型
        有A1/A2亚型，同型仍需交叉配血
        O型：主侧不凝，次侧必凝→“万能供血者”仅限紧急
      RH系统
        D抗原最强（汉族99%阳性）
        母胎不合：Rh(-)母怀Rh(+)胎
          第一胎影响小
          再次妊娠可致胎儿溶血/流产
          需监测抗体滴度，干预
    关键考点问答
      TFPI为何抑制不了生理凝血？
        Ⅲ-Ⅶ可先激活Ⅸ，绕过TFPI
      抗凝三药机制区别
        见抗凝系统
      O型血为何不万能？
        次侧凝集
      Rh阴性母亲一定溶血？
        不一定，主要风险在再次妊娠
      凝血酶两面派
        局部促凝，扩散后抗凝（激活蛋白C）
